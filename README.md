# Praelecta 0.1.0-beta.2

First standalone beta downloads for Praelecta, for making lecture videos from slides, a script, and narration. Optional AI is downloaded separately when selected; installers contain no model bundle or ffmpeg sidecar.

Install and update manually. Praelecta has no automatic updater and is not yet managed by the Thorn & Reason Launcher. Save work and close the app before replacing it; preserve lecture files and application data.

Mac packages are ad-hoc signed and unnotarised. Windows packages are cross-built without Authenticode. Native GUI, installed-update, microphone and audio hardware, video codec/export, screen-reader, and optional-AI acceptance were not performed for this publication. Frontend builds and screenshot captures were checked earlier; broader test suites were skipped by instruction. Screenshot review does not establish accessibility conformance. Media support depends on the operating system and embedded browser; these downloads do not establish that recording or export works on every target.
